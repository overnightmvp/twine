## 🗺️ File Relationship Map

```
index.html
    ├── Loads → base.css (always)
    ├── Loads → template-X.css (dynamic)
    └── Loads → script.js (controls switching)

script.js
    ├── Switches → template-X.css files
    ├── Toggles → Portfolio ↔ Style Guide
    └── Handles → Form submission

base.css
    ├── Provides → Structure & layout
    ├── Defines → Common components
    └── Sets up → Responsive framework

template-X.css
    ├── Extends → base.css
    ├── Defines → Color palette
    └── Adds → Theme-specific styles
```
